# custodia-support

Custodia（歯科医院向け院内管理台帳）のサポートサイト・プライバシーポリシー・サンプル画面。

https://greenhills-dc.github.io/custodia-support/

## パソコン版（Windows ／ macOS）の入手は申込制です

2026 年 10 月から、パソコン版の配布物（Setup.exe・DMG）は GitHub の Releases では配布していません。
使用許諾条項と免責事項にご同意いただいた医院に、ダウンロード用のリンクをメールでお送りします（2 営業日以内）。

- 申込フォーム: https://forms.cloud.microsoft/r/M42YPiiNBA
- 入手方法と使用許諾の要点: https://greenhills-dc.github.io/custodia-support/download.html
- 使用許諾条項（全文）: https://greenhills-dc.github.io/custodia-support/license.html

iPad ／ Mac の App Store 版は、申込なしで App Store から入手できます。
